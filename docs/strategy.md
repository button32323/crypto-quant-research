# 策略说明：现货-永续资金费 carry

## 1. 资金费机制

永续合约无到期日，交易所用**资金费**把永续价格锚定现货：

- 永续价格 > 现货（溢价）→ 多头付给空头（正资金费）；
- 永续价格 < 现货（折价）→ 空头付给多头（负资金费）；
- Hyperliquid 每 **1 小时**结算一次。

## 2. 策略构造

对每个资产（如 PURR、HYPE）：

1. 买入现货 $N；
2. 做空等额永续 $N（1x，不需要杠杆）；
3. 价格涨跌互相抵消（delta-neutral）；
4. 收入 ≈ 资金费 − 交易成本 ± basis 变化。

按本金 $C、sleeve = C/2、最大杠杆 L：

```
名义价值 N = sleeve / (1 + 1/L)
每小时资金费收入 ≈ Σ N_i × funding_rate_i
```

示例：$1,000 资本，PURR maxLev=3 → N=375；HYPE maxLev=10 → N=454.5；资金费率 0.00125%/h 时：

```
每小时 ≈ (375 + 454.5) × 0.0000125 ≈ $0.0104
年化 ≈ 0.0104 × 24 × 365 / 1000 ≈ 9.1%
```

历史平均资金费更高（年化 18% 左右），但会随市场环境大幅波动。

## 3. 收益与风险

| 维度 | 说明 |
|---|---|
| 收益来源 | 正资金费（空头收取）+ basis 收敛 |
| 主要风险 | 资金费转负；basis 走阔（浮亏）；交易所/合约风险；流动性/滑点 |
| 风险特征 | 历史最大回撤 0.74%、年化波动 4.13%，低风险低收益 |
| 容量 | 单资产仓位 ≤ 日成交额 1%（约 $12–14k 总容量） |
| 风控 | 总杠杆 ≤1x；连续 12 次负资金费平仓；回撤 5% 停止；单日亏 2% 停止 |

## 4. 为什么不做方向性交易

项目内 150+ 轮方向性实验（LLM 方向、跨所价差、爆仓反转、OI 拥挤、均线/动量等）在扣手续费与滑点后**全部为负期望**。详见 `docs/historical_validation_report.md` 的复现结论。

## 5. 使用建议

- 先 paper 验证（本仓库的 `paper_hl_carry.py`），满 30 天且满足预注册门禁再考虑实盘；
- 实盘用小规模起步，逐笔授权，API 仅交易权限、禁止提现；
- 不要借钱、不要加杠杆（总杠杆 ≤1x）。
